زاد القلوب 1 — مشروع الويب وتطبيق أندرويد

مهم:
- تم الاحتفاظ بملف index.html الأصلي كما هو دون تعديل محتواه.
- تمت إضافة غلاف Android WebView ليعمل التطبيق كتطبيق أندرويد باسم «زاد القلوب».
- الأيقونة مضافة إلى موارد Android بمقاسات متعددة، والنسخة عالية الجودة موجودة في zad_alqolob_app_icon.png.
- اسم أرشيف التسليم محفوظ كما هو: zad_alqolob_1_final_v2_surahnames_fixed.zip.

بناء APK عبر GitHub:
1. ارفع محتويات هذا الأرشيف إلى المستودع مع الحفاظ على المجلدات، بحيث يكون مجلد .github بجوار مجلد zad_alqolob_1_code.
2. افتح تبويب Actions في GitHub.
3. اختر Build Zad Al Qolob APK ثم Run workflow.
4. بعد نجاح التشغيل، افتح نتيجة التشغيل ونزّل Artifact باسم zad-alqolob-debug-apk.
5. فك ضغط Artifact وثبّت app-debug.apk على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

البناء المحلي:
- يحتاج Android SDK وJDK 17 وGradle 8.9.
- من داخل zad_alqolob_1_code/android نفّذ:
  gradle assembleDebug
- الناتج:
  app/build/outputs/apk/debug/app-debug.apk

الاتصال والخصوصية:
- التطبيق يحتاج إذن الإنترنت لأن ملف الويب الأصلي يستدعي مصادر خارجية لبعض الخطوط والبيانات (ومنها بيانات القرآن/الأحاديث).
- أجزاء البيانات التي يحفظها التطبيق محليًا تظل متاحة وفق آلية الحفظ الموجودة في ملف الويب.
- لم يتم الادعاء بأن جميع مصادر البيانات تعمل دون اتصال قبل اختبارها على الهاتف.
- لم يتم تغيير نصوص أو وظائف index.html في هذه الحزمة.

ملاحظة جودة:
هذه حزمة مشروع قابلة للبناء عبر GitHub Actions، وليست APK جاهزًا. يلزم تشغيل Workflow بنجاح ثم تجربة التطبيق فعليًا على الهاتف، خصوصًا فتح القرآن والأذكار والرقية والأحاديث والنسخ الاحتياطي.
